# Astral Skills — Antigravity

Antigravity n’impose pas forcément le même dossier que Cursor/Codex. Utiliser l’une des options :

## Option A — Rules / skills projet

Copier chaque dossier de `skills/` dans le répertoire de skills/rules reconnu par ton workspace Antigravity.

## Option B — Fichiers joints

Dans le chat :

1. Joindre ou `@` `skills/astral-mvc-development/SKILL.md`
2. Joindre le workflow `workflows/create-astral-app.md` (section 0 remplie)
3. Joindre le brief d’exemple (`examples/shop/` ou `examples/medical-cabinet/`)

## Option C — Coller

Coller le prompt d’exemple (`examples/*/prompt.md`) et rappeler :

> Respecte astral-mvc-development : inspecter le code installé, ne pas inventer d’API, architecture avant code.

## Astral Shop

Utiliser `examples/shop/prompt.md` pour démarrer le cahier des charges sans implémentation.
